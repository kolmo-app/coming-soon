# KOLMO 전환정책 (Transition Policy)

**버전** v0.2 · **상위문서** 00-magna-carta.md · **범위** 변화점 관문(구 골든크로스), G0–G6 전환 관문, 모델 경쟁, 독립재현 정의

## 1. 변화점 관문 (Changepoint Gate)

> v0.1 보정 3: 단순 이동평균 교차(골든크로스)가 아니라 **사전약정 변화점 관문**으로 정의한다. 지속성·확산범위에 더해 오경보 예산, OOD, 데이터 드리프트를 포함한다.

변화점 관문은 신질서의 진리를 증명하는 것이 아니라 **전환검증을 시작시키는 등록된 발동센서**다.

```text
CP_TRIGGER =
    changepoint_score > registered_threshold      # 사전등록 탐지기·임계값
    AND persistence   >= P                        # 지속기간
    AND breadth       >= B                        # 확산범위 (복수 신호/지표)
    AND false_alarm_budget_remaining > 0          # 기간당 오경보 예산 내
    AND ood_check     = PASS                      # 입력이 학습분포 밖이 아님
    AND drift_check   = PASS                      # 데이터 드리프트로 인한 가짜 신호 아님
    AND data_integrity = PASS
    AND decisive_falsifier = NONE
```

1. 탐지기 종류, 임계값, P, B, 오경보 예산, 오류비용은 **결과를 보기 전에** 등록한다. 결과 후 변경은 새로운 실험이다.
2. `CP_TRIGGER` 충족 시 다음 관문으로 이동한다. AI는 통계적 우월성이 충분하지 않다는 이유로 이동을 거부할 수 없다. 위험·불확실성·예상손실은 기록할 수 있지만 권한자에게 재설득을 요구할 수 없다.
3. 전환의 일시 정지는 데이터 무결성 실패 또는 등록된 결정적 반증이 발견된 경우에만 가능하며, 해당 KVU와 헌장조항을 명시해야 한다.
4. 오경보 예산 소진은 탐지기 재보정 사유이지, 개별 전환의 소급 취소 사유가 아니다.

## 2. 전환 관문 G0–G6

| 관문 | 이름 | 내용 |
|---|---|---|
| G0 | 등록 | 주장, 반증조건, 평가기준, 권한자 등록 |
| G1 | 경쟁 | 봉인된 과거사건 + 합성사건에서 현행모델과 경쟁 |
| G2 | 독립재현 | 아래 4절 기준을 충족하는 독립 주체가 결과 재현 |
| G3 | 섀도모드 | 실제 스트림을 읽되 운영결정에 개입하지 않음 |
| G4 | 제한운용 | 일부 경기·사용자·기능에 가역적으로 적용 (카나리) |
| G5 | SOP 반영 | 권한자 승인 운영규칙·분기계획으로 명문화 |
| G6 | 기본질서 | 충분한 운용관찰 후 기본모델/기본규칙으로 채택 |

1. 각 관문은 **진입조건 · 종료조건 · 책임자 · 최대기간 · 롤백조건**을 가진다.
2. 이전 관문을 통과한 결과를 이전 단계의 기준으로 재심해 전환을 막을 수 없다.
3. 경쟁 우승자가 G6로 직접 이동할 수 없다.
4. G2·G3를 통과한 도전자를 막으려면 **새로운 실패근거**를 제시해야 한다. 조직적 불편이나 현행모델의 익숙함은 근거가 아니다.

## 3. 모델 경쟁 원칙

1. 현행·도전자 모델은 동일한 데이터, 시간, 연산한도, 지연조건에서 평가한다.
2. 경쟁 시나리오와 평가함수는 사전등록하며 결과 후 변경하지 않는다.
3. 평가항목 최소 집합: 거짓양성 · 거짓음성 · 탐지지연(lead time) · 확률 보정 · 반사실적 일관성 · 환경변화 강건성 · 연산/지연 비용 · 오류 시 가역성.
4. 헌장 필수제약을 위반한 모델은 평균점수가 높아도 우승할 수 없다.
5. 현상유지 가산점도, 새로움 가산점도 없다.
6. 우승은 진리 확정이 아니라 다음 관문 진입권이다.
7. 실패한 모델·불리한 결과·소수의견도 삭제하지 않고 공개한다.

## 4. 독립재현의 정의

> v0.1 보정 4: 같은 모델에게 두 번 묻는 것은 재현이 아니다.

재현이 "독립"으로 인정되려면 다음 4축 중 **최소 2축**이 원 검증과 달라야 하며, 어느 축이 달랐는지 KVU에 기록한다.

| 축 | 기준 |
|---|---|
| 사람 | 원 검증에 참여하지 않은 검증자 |
| 코드 | 독립 구현된 파이프라인 (포크·공유 라이브러리 최소화) |
| 데이터 분할 | 원 검증이 접근하지 못한 봉인 분할 |
| 기반모델 계보 | 다른 계보의 기반모델/아키텍처 |

동일 조직 내 재현은 허용되나, 승인키는 역할 분리(대헌장 제5조)를 따른다.

## 5. 규범 개정창

- 실행 중: N-v(가치결정)와 등록된 N-h(임계값 등)는 구속력을 가진다.
- 정기 개정창(분기 권장): 축적된 KVU와 실측 결과로 N-h의 반증을 제안할 수 있다. N-v 변경은 제정권자의 명시적 결정으로만 가능하다.

## 6. 전환경보 출력 순서

모든 전환경보는 다음 순서로 출력한다: ① 직접 관측된 변화 ② KOLMO의 추론 ③ 경쟁하는 대안 설명 ④ 변화점 관문 발동상태 ⑤ 반대증거와 무효화 조건 ⑥ 현재 허용된 행동 ⑦ 다음 검증관문 ⑧ 롤백 가능성.
